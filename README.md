# WeatherWise 🌤️

**Check the weather. Plan your day.**

## Project Description

WeatherWise is a web application that helps users check weather conditions and plan their day with personalized clothing and activity recommendations.

This project is developed as part of a web development practices course, focusing on Git, Agile, testing, security, Docker, and CI/CD.

## Planned Features

- Search for a city.
- View current weather conditions.
- Receive clothing recommendations.
- Receive activity recommendations.
- View a 3-day weather forecast.

**Current status:** Initial application setup completed. The frontend is working with a placeholder search response. Live weather API integration is not yet implemented.

## Technologies

- Node.js
- Express.js
- HTML, CSS, JavaScript
- Git and GitHub

## Installation

1. Clone the repository:

   `git clone https://github.com/noater/weatherwise.git`

2. Open the project folder:

   `cd weatherwise`

3. Install dependencies:

   `npm install`

4. Start the server:

   `node server.js`

5. Open the application in your browser:

   `http://localhost:3000`

On Windows PowerShell, use `npm.cmd install` if the `npm` command is blocked.

## Project Structure

- `server.js` — Express web server
- `public/index.html` — Page structure
- `public/style.css` — Website styling
- `public/script.js` — Frontend interaction
- `package.json` — Project settings and dependencies
- `package-lock.json` — Locked dependency versions

## Development Workflow

Development follows an Agile Kanban workflow using GitHub Projects.

New features are developed on separate Git branches and submitted through Pull Requests for peer review before being merged into `main`.
